# FP&A Trends Web

An experimental public web interface for exploring FP&A trends, finance intelligence, interactive visualization, and AI-assisted product concepts.

## Security / data boundary

This repository is a public static-site experiment. Client-side HTML/JavaScript cannot provide a meaningful secret or access-control boundary, so the interface should not imply that a browser password protects private content.

Only synthetic, public, or appropriately licensed data belongs here. Employer, client, family, personal production data, credentials, and private databases do not.

## Project context

This is a personal, self-directed learning project by João Caldas. I use projects like this to learn software engineering, interactive visualization, FP&A product design, AI systems, and web technologies through hands-on experimentation.

AI tools are used extensively during research, design, coding, debugging, testing, and documentation. AI-generated suggestions are inputs to review rather than proof of correctness.

## Portfolio role

This project is primarily a visual/operator-console experiment. Reusable finance calculations and data contracts should live in tested modules or dedicated finance projects rather than being duplicated inside a single static page.
